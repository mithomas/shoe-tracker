topic: Shoe Tracker UX
updated: 2026-10-28T12:38

- (decision) Form-factor: Mobile-first smartphone web app; 3 bottom tabs (Spot, Map, List)
- (decision) Visual Identity: Dark slate asphalt theme (#12151B) with high-contrast signal amber/orange action button (#F97316) and signal blue (#3B82F6) for user own shoes
- (decision) Main Action: Giant centered circular button (min 200px) for instantaneous single-tap spotting
- (decision) Cooldown Feedback: Circular progress ring with 3s countdown text, tactile button depress, and toast confirmation
- (decision) GPS Status Indicator: Visible badge in header showing live GPS lock state (Ready / Acquiring / Denied)
- (decision) Onboarding: First-run modal prompt for user name, storing to localStorage user_id
- (decision) Map Markers: Signal blue for user's own shoes, muted slate for other users; toggle pill for 'Only my shoes'
- (event) UX discovery fast path completed
- (decision) Posture: Not mission-critical; a fun, playful highway road-trip utility.
- (decision) Post-Tap Modal: After pressing the spot button, display a confirmation modal showing sighting coordinates, timestamp, and confirm/dismiss.
