topic: Database Modernization & GraalVM Native Image
updated: 2026-10-29T16:21
---


- (decision) Fresh start: SQLite completely retired without migration scripts; Flyway generates fresh H2 schema on boot.
- (decision) Schema DDL: Native TIMESTAMP(3) columns with CURRENT_TIMESTAMP(3) default in V1__init_sightings.sql.
- (decision) Exception mapping: Replace SQLiteExceptionMapper with unified DatabaseContentionExceptionMapper matching ANSI SQLState codes (40001, 57P01) for 503 Service Unavailable.
- (decision) Dynamic health probe: DatabaseHealthCheck inspects conn.metaData.databaseProductName for health report.
- (decision) Unified datasource config: Both H2 and MariaDB/MySQL drivers are bundled internally and switched automatically at startup based solely on the driver prefix in the single `QUARKUS_DATASOURCE_JDBC_URL` environment variable (`jdbc:h2:file:...` vs `jdbc:mariadb://...`). H2 in-memory mode dropped as a user-facing runtime target.
- (decision) Native compilation: GraalVM in-container Mandrel build with Dockerfile.native and `@RegisterForReflection` on REST DTOs targeting sub-50ms cold starts.
- (decision) Story sequencing: Linear single-lane execution (`6.1 -> 6.2 -> 6.3 -> 6.4 -> 6.5`) with Story 6.1 as tracer bullet removing all `org.sqlite.*` references so every story compiles and passes `./gradlew check test`.
- (requirement) R23: Embedded H2 database (quarkus-jdbc-h2) replaces SQLite with native TIMESTAMP(3) DDL and lock-free concurrency while preserving @Startup @PostConstruct fail-fast SELECT 1 validation.
- (requirement) R24: Unified DatabaseContentionExceptionMapper translates SQLState 40001/40P01/57P01/HYT00 and H2/MariaDB lock codes across causal SQLException chains to RFC 7807 503.
- (requirement) R25: DatabaseHealthCheck dynamically reports database product name in /q/health/ready under "Database connection health check".
- (requirement) R26: Configurable datasource bundles H2 and MariaDB/MySQL internally and switches at startup from a single QUARKUS_DATASOURCE_JDBC_URL string (H2 file or external MariaDB/MySQL).
- (requirement) R27: Quarkus GraalVM native binary builds via Dockerfile.native achieving sub-50ms cold starts.
- (event) Epic 6 refined, grilled, and hardened.
- (requirement) Story 6.3: Document datasource configuration options (default H2 file and external MariaDB/MySQL via single JDBC URL) with environment variable examples in root README.md, and update Dockerfile and docker-compose.yml default JDBC URLs from SQLite to H2 file.
