updated: 2026-10-29T16:21

- (decision) Fresh start: SQLite completely retired without migration scripts; Flyway generates fresh H2 schema on boot.
- (decision) Schema DDL: Native TIMESTAMP(3) columns with CURRENT_TIMESTAMP(3) default in V1__init_sightings.sql.
- (decision) Exception mapping: Replace SQLiteExceptionMapper with unified DatabaseContentionExceptionMapper matching ANSI SQLState codes (40001, 57P01) for 503 Service Unavailable.
- (decision) Dynamic health probe: DatabaseHealthCheck inspects conn.metaData.databaseProductName for health report.
- (decision) Unified datasource config: Runtime env vars allow selecting external MySQL/MariaDB, H2 file-based persistence (/data), or H2 in-memory via QUARKUS_DATASOURCE_*.
- (decision) Native compilation: GraalVM in-container Mandrel build with Dockerfile.native targeting sub-50ms cold starts.
- (requirement) R23: Embedded H2 database (quarkus-jdbc-h2) replaces SQLite with native TIMESTAMP(3) DDL and lock-free concurrency.
- (requirement) R24: Unified DatabaseContentionExceptionMapper translates SQLState 40001/57P01 contention to RFC 7807 503.
- (requirement) R25: DatabaseHealthCheck dynamically reports database product name in /q/health/ready.
- (requirement) R26: Configurable datasource supports MySQL, H2 file, or H2 in-memory via single env configuration.
- (requirement) R27: Quarkus GraalVM native binary builds via Dockerfile.native achieving sub-50ms cold starts.
